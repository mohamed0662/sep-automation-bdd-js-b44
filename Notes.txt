Agents: A specialist role with behavior and allowed tools

Skills: Reusable task instructions


BDD layers:

    1. Business layer
            Create feature files for scenarios (Declarative steps) - written in Gherkin
              Write Scenarios

    2. Technical layer
            Generating Step definitions -> work on the automation script

POM (Page Object Model):
        for each web page, we create a page class.
        We will store web page' elements and actions in its page class.
        which allows us to reuse them in tests


Manual Testing Workflow:

     1- Analyzing the requirements
               -If any clarifications needed ===> business team (BA or PO)

     2- Explore the application to understand the behavior of the application

     3- Create manual test cases  
           -Gherkin syntaxes
           -Xray steps 

Automation Testing Workflow:

     1- Create a seperate branch for the user story

     2- Work on features folder:
          -add the scenarios into the feature files

     3- work on the steps folder:
          -Generating step definitions
          -work on the body of the step definitions
          (any web element or page actions, we create them under the pages)

     4- Run the test and review the report:
          -Determines the result of pass or failed

          If passed ===> go to step 5

          If Failed: 
                RCA (Root Cause Analysis)
                Determine why test is failed
                Analyze if it failed due to the product defect that i should be reporting 
                

     5- Push to the github feature branch, create Pull Request
